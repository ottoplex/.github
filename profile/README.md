## 🌌 关于御行枢控

**御行枢控（OttoPlex）** 是面向无人机及具身智能终端打造的新一代 **智能体平台（Agent Platform）**。

传统无人机系统更多采用：

> **人下达指令 → 飞控执行 → 人观察结果**

而御行枢控希望构建一种新的交互与执行范式：

> **人提出目标 → 智能体理解任务 → 自主规划 → 终端感知 → 无人机执行 → 实时反馈 → 动态决策**

平台将云端/中心侧的 **智能体决策能力** 与边缘侧 **具身智能终端** 深度结合，使 AI 不仅能够理解信息，更能够通过无人机感知真实世界、执行物理动作，并根据环境反馈持续调整任务。

御行枢控的核心目标是：

**让无人机从“被控制的飞行设备”，逐步演进为“能够理解目标并自主完成任务的具身智能体”。**

### 🧠 智能体平台

负责解决“**想做什么、为什么做、怎么做**”。

核心能力包括：

* 🎯 **任务意图理解**：理解自然语言、结构化指令以及多模态任务目标。
* 🧩 **任务分析与拆解**：将复杂任务拆解为可执行的任务步骤。
* 🧠 **智能推理**：结合任务上下文、历史记忆、地图、设备状态和视觉信息进行决策。
* 🗺️ **任务规划**：生成航线、观察策略、执行顺序和任务计划。
* 🔄 **动态决策**：根据实时环境和执行反馈动态调整任务。
* 🤝 **智能体协同**：支持多个专业 Agent 协同完成复杂任务。
* 🧠 **空间记忆**：沉淀任务区域、目标、历史事件和空间关系。

### 📦 具身智能终端

负责解决“**现场怎么看、现场怎么规划、现场怎么执行**”。

终端盒子连接 AI 与真实物理世界，具备：

* 👁️ **多模态感知**
* 🧭 **边缘自主规划**
* 🧠 **实时推理**
* 🎮 **无人机控制**
* 🎥 **视频与图像处理**
* 📍 **定位与空间理解**
* ⚡ **低时延执行**
* 🛡️ **安全状态监控**
* 🔌 **多类型设备接入**

通过终端盒子，可以将智能体产生的高层任务转换为实际的飞行、拍摄、跟踪、喊话等物理动作。
